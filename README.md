# 大学・団体名簿

大学名・団体名を登録すると、都道府県から地域別に自動で並ぶ名簿です。
ページは GitHub Pages、データは Supabase（無料のデータベース）に置きます。
ログインした人だけが名簿を見たり、登録・編集・削除したりできます。

登録できる項目：大学名（または「その他（大学名なし）」）、団体名、都道府県（任意）、連絡手段、投票日、投票時間、応援コメント（◯✕）、返信確認、Nociws側詳細（投票日・投票時間・応援コメント）、メモ。

一覧は「登録順（新しい順）」「地域順」「五十音順」「投票日順（早い順）」「Nociws投票日順（早い順）」で並べ替えられます。同じ大学が2件以上登録されていると、大学名が赤字になり「重複」と表示されます。

**項目を増やしたあとは、`setup.sql` をもう一度 SQL Editor で実行してください。**（何度実行しても登録済みのデータは消えません）

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（見た目と枠組み） |
| `app.js` | 画面の動き（登録・検索・絞り込み・ログイン） |
| `config.js` | 保存先の設定。**ここだけ自分で書き換えます** |
| `setup.sql` | Supabase に最初に1回だけ実行する設定 |

## Supabase を設定する前に試す（お試しモード）

1. 5つのファイルを同じフォルダに入れます。
2. `index.html` をダブルクリックして、ブラウザで開きます。
3. 「お試しモードで使ってみる」を押します。

お試しモードのデータは、そのブラウザの中だけに保存されます。他の人や他の端末には共有されず、Supabase を設定したあとの名簿にも引き継がれません。

## 手順1：Supabase に保存先を作る

1. https://supabase.com を開き、「Start your project」からアカウントを作ります（GitHub アカウントでログインできます）。
2. 「New project」を押します。
3. 名前（例：`meibo`）、データベースのパスワード（自動生成でよい）、地域（`Northeast Asia (Tokyo)`）を選び、「Create new project」を押します。準備に1〜2分かかります。
4. 左のメニューの「SQL Editor」を開きます。
5. `setup.sql` の中身を全部コピーして貼り付け、「Run」を押します。「Success」と出れば完了です。

## 手順2：ログインできる人を決める（重要）

**この手順を飛ばすと、誰でも自分でアカウントを作って名簿を見られてしまいます。**

1. 左のメニューの「Authentication」を開きます。
2. 設定画面（「Sign In / Providers」など）で「Allow new users to sign up」を**オフ**にして保存します。
3. 「Authentication」→「Users」→「Add user」→「Create new user」を押します。
4. 使う人のメールアドレスとパスワードを入れ、「Auto Confirm User」にチェックを入れて作成します。
5. 名簿を使う人数分、3〜4 を繰り返します（全員で1つのアカウントを共用しても動きます）。

## 手順3：config.js を書き換える

1. Supabase の「Project Settings」→「API」（または「API Keys」「Data API」）を開きます。
2. 「Project URL」（`https://xxxx.supabase.co`）をコピーし、`config.js` の `supabaseUrl: ""` の `""` の間に貼ります。
3. 「anon」「public」または「publishable」と書かれたキーをコピーし、`supabaseKey: ""` の `""` の間に貼ります。

**`service_role` や `secret` と書かれたキーは絶対に貼らないでください。** それは全データを操作できる管理用の鍵です。

## 手順4：GitHub Pages で公開する

1. リポジトリの「Settings」→「Pages」を開きます。
2. 「Source」で「Deploy from a branch」を選びます。
3. 「Branch」で `main` と `/ (root)` を選び、「Save」を押します。
4. 1〜2分待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

一覧ページを直接開くには、URL の末尾に `#list` を付けます。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「初期設定がまだ終わっていません」と出る | `config.js` の URL とキーが `""` の中に正しく入っているか |
| ログインできない | 手順2でユーザーを作ったか、「Auto Confirm User」にチェックを入れたか |
| 「名簿を読み込めませんでした」と出る | 手順1の `setup.sql` を実行したか。長期間使っていない場合、Supabase 側でプロジェクトが一時停止していないか |
